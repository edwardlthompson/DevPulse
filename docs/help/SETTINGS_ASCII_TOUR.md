# Settings-only chrome (ASCII tour)

Video-free map of the Golden Path shell (web + Android):

```
┌──────────────────────────────────────────┐
│  [App title]              [⚙ Settings]   │  ← Home: Settings gear only
├──────────────────────────────────────────┤
│                                          │
│           greeting / status              │
│                                          │
└──────────────────────────────────────────┘

Settings
┌──────────────────────────────────────────┐
│  [←] Settings                            │
├──────────────────────────────────────────┤
│  🔍 search…                              │
│  Appearance → theme                      │
│  Privacy → save crashes                  │
│  Data → export / import                  │
│  About → app info  ─────────────────┐    │
└─────────────────────────────────────│────┘
                                      ▼
About
┌──────────────────────────────────────────┐
│  version · installed format (apk|aab)    │
│  update status · donate methods          │
│  Report bug / Request feature ──────┐    │
└─────────────────────────────────────│────┘
                                      ▼
Feedback
┌──────────────────────────────────────────┐
│  description · preview · copy · open GH  │
│  Discard → confirms then pops stack      │
└──────────────────────────────────────────┘
```

No bottom tab bar. Donate lives under About only. TalkBack: home status has a contentDescription; Back icon only when not at Home.
