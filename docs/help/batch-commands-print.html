How to print: open this file in a browser, then use Print (Ctrl+P or Cmd+P). Landscape is optional.

Agent shortcuts

Type / in Cursor Agent chat, then pick a name. Slash commands are Cursor-only; other tools read the matching file under docs/help/. First-time autonomous work: Cline in Cursor (review every diff). Do not paste API keys.

Publishing: /push and /ship send code to GitHub. Run them only when you intend to publish.

Big jobs

Type thisWhen to use it
/bootstrapSet up a brand-new project from scratch, then take the tour.
/verifyCheck your work (docs, local tests, CI) before you open a pull request.
/buildWork through the task board, one feature at a time.
/shipPublish a release to GitHub. This pushes your code.
/maintainWeekly health pass: security, dependencies, and a full review.

Getting started

Type thisWhen to use it
/tourA 10-minute walkthrough. Home chrome is Settings-only.
/initFirst-time setup: name, stack, and project files.
/setupTurn on GitHub settings this template expects.
/pruneKeep only the stack you chose; drop unused examples.
/coachAsk what to do next. Theme, About, and donate stay in Settings (Settings-only).
/ideasSee a short ranked list of possible next features (does not build them).
/allideasDump every in-scope idea so you can fill the task board.

Building

Type thisWhen to use it
/planDesign one feature or decision before coding.
/adrWrite the next numbered architecture decision record.
/featureBuild one feature slice with tests, then run checks.
/fixRepair failing checks after a build, in the feature you just touched.
/cleanupArchive finished task-board rows so the list stays short.
/scopeSplit work so more than one agent can help without colliding.

Docs and checks

Type thisWhen to use it
/gatesRun the local checks that match CI (no GitHub wait).
/docsCheck README health, tables, and file encoding.
/ciWait for GitHub Actions after a push (checks only, no new commit).
/debugInvestigate a bug with logs and evidence (not a full-repo audit).

Publishing

Type thisWhen to use it
/update-depsScan and apply safe local dependency bumps.
/prereleaseRun pre-release checks without pushing.
/pushCommit, push to GitHub, and cut a release. This publishes.
/regressAfter a release: confirm SBOM, Pages, and the upgrade simulation.

Local hardware
